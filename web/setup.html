Edge setup

Architecture

The edge

This PC serves the phone's page and passes what happens on to the backends.

Adapters

Node-RED: install node-red-contrib-dhc-edge, add a “dhc edge” config node with this address and the token from .edge/token.

Connect the phone

  1. On the phone: Settings › About phone › tap “Build number” seven times.
  2. Settings › Developer options › turn on “USB debugging”.
  3. Plug the phone into this PC and allow it on the phone.
  4. On this PC, in the edge's folder:
    ./scripts/usb.sh
  5. The page opens on the phone: tap ▶.

USB makes the page the phone's “localhost”: a secure page, so the camera works without certificates. The cable charges the phone too.

Without HTTPS the tiles work, but the camera is blocked on Wi-Fi. Use USB, or start the edge with a certificate: ./start.sh --make-cert

The profile

What the phone shows. A tap here pretends to be the phone (steps get sample answers), so a flow can be tried without one.

This profile takes photos: they go from the phone to the backends, inside the tile's event. The edge keeps none (the last few, in memory, for this page).
